# panlabs

Um laboratório pessoal de desenvolvimento de software: um mantenedor e agentes autônomos operando de ponta a ponta, do ticket ao merge.

A tese desta org não é o portfólio de soluções — é o método. Cada repo aqui é trabalho especificado, decidido e implementado por agentes com autonomia real de execução: decompõem spec em tickets, implementam em TDD, abrem PR e mergeiam no verde sem intervenção humana no caminho feliz. Decisão relevante vira ADR (registro de decisão de arquitetura), versionada ao lado do código que ela justifica. As skills que orientam os agentes também são versionadas — equipamento auditável, não configuração perdida numa máquina.

O padrão que governa como um repo desta org se organiza mora em [`.github`](https://github.com/panlabs-tech/.github), o repo meta que carrega a própria definição.

## As soluções

O que esse método produz mora em **[panlabs.tech](https://panlabs.tech)**, a vitrine das soluções que passaram no gatilho de avaliação — o crivo que decide o que sai de laboratório e vira produto. Perfil e site respondem por audiências diferentes — aqui é o método, lá é o produto — sem sincronia automática entre os dois.
