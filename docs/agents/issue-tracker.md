# Issue tracker

As issues deste repo vivem como **issues do GitHub** em `panlabs-tech/.github`. Use a CLI `gh` para todas as operações.

> **Atenção ao alvo.** Este repo tem nome iniciado por ponto, então o clone local é um **diretório oculto**. A inferência do `gh` pelo `git remote` funciona normalmente de dentro dele, mas passe `-R panlabs-tech/.github` explicitamente quando estiver rodando de fora.

## O que entra

Trabalho sobre o **padrão panlabs**: configuração da org, ambiente da máquina de desenvolvimento, anatomia de repo, CI compartilhada, conformidade.

Trabalho sobre **produto** não entra — cada solução tem seu próprio tracker.

## O que não é superfície de triagem

**PRs externos.** Esta é uma org de um mantenedor; PR de fora não faz parte do fluxo de triagem.

## Registro histórico

O mapa de wayfinding que originou este repo ([panlabs-tech/panlabs#46](https://github.com/panlabs-tech/panlabs/issues/46)) e seus 21 tickets de decisão permanecem em `panlabs-tech/panlabs`. Eles são **arquivo**, não trabalho vivo — não abra issue lá.
